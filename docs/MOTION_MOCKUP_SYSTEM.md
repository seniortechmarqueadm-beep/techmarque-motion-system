# Motion mockup system

Use image generation for environment, lighting, plates, products, materials, and texture. Use Remotion for exact text, captions, logos, UI, data, safe areas, timing, and CTA.

Before a multi-frame mockup, create `MOTION_MOCKUP_SPEC.yaml` and `FRAME_ANCHOR_MAP.yaml`. Generate a styleframe without critical text or fake UI, inspect it, then compose deterministic overlays in Remotion. Review opening, reveal, dense content, transition, and CTA at the target mobile canvas.

Persist only approved chat decisions through a reviewed handoff. Do not store raw transcripts in this workspace.
