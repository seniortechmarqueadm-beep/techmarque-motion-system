# Adapter VSCode

Abra o root que contém `AGENTS.md` e `package.json`. Use o terminal integrado
para `discover`, `route`, `plan` e `validate`. Não espalhe instruções em arquivos
soltos fora de `.codex/` sem atualizar o manifest.

Para um novo criativo, revise o JSON/YAML de brief e route antes de abrir o
scaffold. O editor visualiza o código; o gate visual ainda exige render ou
still realmente observado.
